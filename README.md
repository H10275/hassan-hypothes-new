# HASANI Modular Prime & Goldbach Framework

This repository contains C++ modules for analyzing prime numbers, testing Goldbach's conjectures (even and odd), and exploring structural generation models using Hassan's empirical sieve logic.

## 📁 Folder Structure

- `headers/` — C++ header files for model definitions
- `rsc/` — Input files, configuration data, and expected results
- `EvenGoldbach/` — Models and tests for even-number Goldbach representations
- `OddGoldbach/` — Generators and models for odd-number Goldbach representations
- `PrimeModels/` — Empirical classification of prime numbers
- `CompositeModels/` — Modular classification of composite numbers
- `Conjectures/` — Hassan's original conjectures and generative logic
- `Tests/` — Range and single-value test cases
- `Docs/` — Bilingual documentation and theoretical background

## 🧪 Usage

1. Compile any `.cpp` file using a C++ compiler.
2. Provide input manually or via `rsc/` files.
3. Review output and compare with expected results.
